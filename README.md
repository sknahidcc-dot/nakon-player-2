# Nakon-Player (v21.35.442) 🎬

ইউটিউব (v21.35.442) এর মতো সম্পূর্ণ অফলাইন লোকাল ভিডিও প্লেয়ার অ্যান্ড্রয়েড অ্যাপ। কোনো লগইন প্রয়োজন নেই, ডিভাইসের সব ভিডিও তাৎক্ষণিক প্লে করতে পারে।

## 📱 ফোন দিয়ে GitHub থেকে APK বানানোর সহজ নিয়ম (No Computer Needed)

আপনি কোনো কম্পিউটার ছাড়াই শুধুমাত্র আপনার ফোন দিয়ে GitHub Actions ব্যবহার করে APK তৈরি করে ডাউনলোড করতে পারবেন। নিচে ধাপগুলো দেওয়া হলো:

### ধাপ ১: প্রজেক্টটি GitHub-এ আপলোড করুন
- AI Studio-এর **Export / Push to GitHub** বাটনে ক্লিক করে এই রিপোজিটরিটি আপনার GitHub অ্যাকাউন্টে পুশ করুন (বা সরাসরি রিপো হিসেবে ওপেন করুন)।

### ধাপ ২: মোবাইল ব্রাউজার দিয়ে GitHub খুলুন
- আপনার ফোনের ক্রোম (Chrome) বা যেকোনো ব্রাউজারে আপনার GitHub রিপোজিটরি লিঙ্কে যান।
- রিপো পেজের ওপরের মেনু থেকে **"Actions"** ট্যাবে ক্লিক করুন।
  *(মোবাইলে Actions ট্যাব না দেখলে ব্রাউজারের থ্রি-ডট মেনু থেকে "Desktop site" অন করে নিন)*।

### ধাপ ৩: APK বিল্ড চালু করুন
- বামপাশের ওয়ার্কফ্লো তালিকা থেকে **"Build Android APK"** সিলেক্ট করুন।
- ডানে থাকা **"Run workflow"** নীল বাটনে ট্যাপ করুন।
- তারপর ড্রপডাউন থেকে **"Run workflow"** নিশ্চিত করুন।

### ধাপ ৪: APK ডাউনলোড ও ইন্সটল করুন
- বিল্ড শুরু হয়ে ২-৩ মিনিটের মধ্যে সম্পন্ন হবে এবং সবুজ টিকমার্ক (Green Checkmark) আসবে।
- সফল বিল্ডে ক্লিক করুন:
  1. **Option 1 (Direct Download):** রিপোজিটরির **"Releases"** অপশনে গিয়ে সরাসরি `Nakon-Player-v21.35.442.apk` ফাইলের ওপর ক্লিক করলেই সরাসরি ডাউনলোড হয়ে যাবে!
  2. **Option 2 (Artifacts):** ওয়ার্কফ্লো সামারির নিচে **"Artifacts"** সেকশনে `Nakon-Player-v21.35.442-APK` ফাইলে ক্লিক করে ডাউনলোড করে নিন।
- ডাউনলোড শেষে ফোনে ট্যাপ করে সরাসরি ইনস্টল (Install) করে উপভোগ করুন!
